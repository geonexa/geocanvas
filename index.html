Welcome to GeoCanvas

GeoCanvas is a fast, free, and lightweight tool for drawing, uploading, and analyzing spatial data directly in your browser. No account required - everything runs locally.

File Support

You can upload and visualize the following spatial formats:

  • GeoJSON / JSON
  • KML / KMZ
  • Shapefiles (.zip) with all component files included
Feature Inspector
  • View feature properties
  • Edit, delete, or add new attribute fields
  • View geometry information (area, perimeter, length)
